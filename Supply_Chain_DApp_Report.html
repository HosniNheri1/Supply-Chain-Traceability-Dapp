01 — Overview

From the factory to the shelf, with every step on-chain

A normal database can be edited by whoever administers it. This project keeps the history of a product on Ethereum instead: each stage change is a signed transaction, stamped with block.timestamp and recorded as an event that anyone can read on Etherscan. Nothing here is theoretical — every command and screenshot in this report comes from a real run.

📦 Track

Four stages — Manufactured, Shipped, In transit, Delivered — and a checkpoint list per product, with location, note and actor.

🕒 Timestamp

Every checkpoint stores block.timestamp and emits a ProductCreated or StageUpdated event, readable by anyone.

🔐 Control

Three roles (manufacturer, transporter, retailer) via OpenZeppelin, and a stage guard that rejects skipped or repeated steps.

🌐 Interface

A web page that connects MetaMask, creates products, updates stages and draws the full timeline of any product ID.

02 — Phase 1

Smart contract: roles, stages and an append-only history

The contract SupplyChain.sol keeps a Product record and an array of Checkpoint records per product. The history only grows: no function edits or deletes a past checkpoint, so the current stage can change but the past stays visible.

FunctionWho can call itEffect
createProduct(name, location)ManufacturerNew product at stage Manufactured, first checkpoint stored
shipProduct(id, location, note)ManufacturerManufactured → Shipped
updateTransit(id, location, note)TransporterShipped / In transit → In transit (repeatable)
confirmDelivery(id, location, note)RetailerIn transit → Delivered
getProduct(id) · getHistory(id)AnyoneFree reads of the product and its checkpoints
enum Stage { Manufactured, Shipped, InTransit, Delivered }

struct Checkpoint {
    Stage   stage;
    address actor;
    uint256 timestamp;   // block.timestamp
    string  location;
    string  note;
}

function shipProduct(uint256 productId, string calldata location, string calldata note)
    external onlyRole(MANUFACTURER_ROLE) productExists(productId)
{
    _requireStage(productId, Stage.Manufactured);   // reverts with InvalidStage
    _moveTo(productId, Stage.Shipped, location, note);
}
Design choices — custom errors (InvalidStage, ProductNotFound) cost less gas than revert strings; events make the history searchable without reading storage; roles come from an audited library instead of hand-written checks.
03 — Phase 2

Local tests: Hardhat Network before any public network

Hardhat compiles the contract and runs 10 automated tests (roles, creation, full lifecycle, events and guards). Then a persistent local Ethereum node (chain ID 31337) was started to try the real web page against a real chain, at no cost.

npm install
npx hardhat test                                         # 10 passing
npx hardhat node                                         # terminal 1: local blockchain
npx hardhat run scripts/deploy.js --network localhost    # terminal 2
npx http-server frontend -p 3000 -c-1                    # terminal 3: web page
Wrong folder — HHE3: No Hardhat config file found. The new terminal had opened in the home directory instead of the project folder. Fixed by running cd into the project before every command.
04 — Phase 3

Deployment on the Sepolia testnet

The final deployment is mandatory on Sepolia, the public Ethereum test network. It needs three things: a funded test wallet, an RPC endpoint, and the secrets kept out of the code in a .env file.

# .env  (listed in .gitignore, never committed)
SEPOLIA_RPC_URL=https://eth-sepolia.g.alchemy.com/v2/<your-key>
PRIVATE_KEY=<dedicated test wallet, no real funds>
ETHERSCAN_API_KEY=<your-key>

npx hardhat run scripts/deploy.js --network sepolia

Getting test ETH

Gas must be paid in Sepolia ETH. Most faucets refused a brand-new wallet, so the proof-of-work faucet was used: the browser mines for a few minutes, then the reward is claimed on-chain.

Faucets requiring mainnet funds — the Alchemy faucet asked for 0.001 ETH on mainnet, Chainlink for 1 LINK, and QuickNode for a mainnet balance, all to prevent abuse. A new test wallet has none of that, so these three could not be used.
VPN blocked — the PoW faucet answered IP Blocked: you're connecting from a hosting IP range because a VPN was running. Fixed by turning the VPN off.
05 — Phase 4

Web interface and public proof

The page loads ethers.js v6, connects to MetaMask with BrowserProvider, builds a Contract from the ABI and the deployed address, and calls the four write functions and the two read functions. Reads are free through the RPC; writes pop up a MetaMask confirmation and wait for the block.

Chain validated — from wallet signature to public proof, every step of the lifecycle was executed on Sepolia and confirmed by the page, by the contract's own read functions, and by the events on Etherscan.
06 — Troubleshooting

What actually broke (and how it was fixed)

In the interest of honest documentation, here are the real incidents met along the way — the moments that build operational skill, not the steps that worked on the first try.

MetaMask not found. The page was first opened in a browser view without the extension installed. Fixed by installing MetaMask and opening localhost:3000 in the normal browser window.
Network locked per site. Sepolia could not be selected while the localhost tab was active, because MetaMask only allows the networks a site was approved for. Fixed by switching network from a neutral tab, then adding Sepolia to the site's permissions.
Address pasted instead of private key. Importing the Hardhat account failed with Cannot import invalid private key: the public address had been copied, not the key. Fixed by copying the value on the Private Key: line printed by npx hardhat node.
missing revert data after a node restart. The local chain had been reset, so the old contract no longer existed and MetaMask kept stale data. Fixed by clearing the activity data, redeploying, and restarting the web server with caching off.
Port 3000 already in use. EADDRINUSE and a 404 page: an older http-server was still running from the wrong folder. Fixed by stopping the process on port 3000 and restarting the server from the project folder.
Wrong currency symbol. MetaMask suggested GO for chain ID 31337 because another public test chain uses the same ID. Fixed by naming the network "Hardhat Local" with symbol ETH.
Credential hygiene. The deployment key lives in .env, excluded from Git, and belongs to a dedicated test wallet with no real funds. The Hardhat account key is public by design, so it was used only on the local network, never on Sepolia.
